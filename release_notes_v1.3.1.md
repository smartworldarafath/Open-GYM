# Open-GYM v1.3.1 Release Notes

Welcome to **Open-GYM v1.3.1**! This update introduces modern, transparent glassmorphism UI styling across key app components, refined navigation elements, and performance improvements.

---

### ✨ What's New & Highlights

#### 1. Transparent Glassmorphism UI Overhaul
- **Home Screen**:
  - **Start Workout Hero Button**: Upgraded to a sleek frosted glass pill with translucent ambient blur and subtle specular sheen.
  - **Routines, Tools, Journal Cards**: Beautiful transparent folder flaps with backdrop blur showcasing underlying workout logs.
  - **Streak Pill**: Frosted glass badge for your daily streak counter.
- **Progress & Sharing**:
  - Frosted circular share action button in top navigation.
  - Transparent glassmorphic **Share** action button inside the social export sheet.
- **Exercises Screen**:
  - Clean frosted glass **+ (Create Exercise)** action pill.
- **Profile Screen**:
  - Frosted glass **Edit Profile** button.
  - Transparent glass circular quick-action icons for Sharing and Settings.
- **Settings & Places**:
  - **UI Color Switcher**: Translucent glass dock indicator.
  - **Units Switcher (kg / lb)**: Frosted glass toggle dock.
  - **My Places**: Glassmorphic location cards (Gym, Home, Outdoors) and "+ New place" launcher.
  - **Import from another app**: Glass **Choose File** selector button.
  - **About Card**: Ambient frosted glass container highlighting the runner visual while keeping all typography and badges razor-sharp.
  - **App Updates**: Translucent glass **Check Again** button.

#### 2. Architecture & Engine Optimizations
- Resolved Kotlin compilation cache issues across Windows and Android environments.
- Optimized shader pipelines and asset bundling.
- Bumped app version to **1.3.1+4**.
